**Planner\_AI\_Agent: 자율 AI 에이전트 프로젝트**

Planner\_AI\_Agent는 복잡한 작업을 자율적으로 수행하는 AI 에이전트의 진화 과정을 담은 프로젝트입니다.

본 프로젝트는 현재 두 가지 버전으로 구성되어 있습니다:

  * **v1.0 (Stable):** React 프론트엔드와 **FastAPI** 기반으로 통신하는 독립된 Python 백엔드 모듈을 갖춘 안정적인 클라이언트-서버 아키텍처입니다.
  * **v2.0 (In Development):** 백엔드를 LangGraph 기반으로 고도화하고, 기존 백엔드의 **데이터 수집/정제 로직을 프론트엔드와 직접 통합**하여 반응성을 극대화하는 것을 목표로 하는 차세대 아키텍처입니다.

-----

### 📌 프로젝트 현황 및 아키텍처

#### v1.0 (Stable): 분리된 클라이언트-서버 아키텍처

초기 안정화 버전은 웹 개발의 표준 패턴에 따라 \*\*사용자 인터페이스(클라이언트)\*\*와 \*\*핵심 로직(서버)\*\*을 명확하게 분리했습니다. 특히, 백엔드 내에서도 데이터 수집/정제 로직을 별도의 모듈로 분리하여 유지보수성을 높였습니다.

구조:

  * **Frontend (Client):** React로 개발된 동적인 사용자 인터페이스. 사용자의 요청을 받아 백엔드 API를 호출하고 응답을 시각화합니다.
  * **Backend Agent (Server):** Python으로 개발된 독립적인 에이전트. **FastAPI** 서버 역할을 하며, 내부적으로 분리된 데이터 수집/정제 모듈을 호출하여 작업을 수행합니다.

아키텍처 및 통신 흐름:
\+------------------+     (HTTP Request)      +-----------------------------+
| React Frontend   |------------------------\>| Python Backend Agent (API)  |
| (Client)         |\<------------------------|  - Data Collection Module   |
\+------------------+     (JSON Response)     |  - Data Refinement Module   |
\+-----------------------------+

#### v2.0 (In Development): 차세대 통합 그래프 아키텍처

현재 개발 중인 차세대 버전은 LangGraph를 도입하여 백엔드 로직을 고도화하는 동시에, v1.0의 분리된 **데이터 수집/정제 로직을 프론트엔드와 직접 통합**하여 더욱 실시간적이고 동적인 사용자 경험을 제공하는 것을 목표로 합니다.

목표:

  * **동적이고 유연한 작업 흐름:** 복잡한 작업을 그래프 구조로 계획하고, 상황에 따라 실행 흐름을 동적으로 변경합니다.
  * **프론트엔드-데이터 로직 통합:** 데이터 처리 과정을 프론트엔드와 긴밀하게 결합하여 응답 속도와 상호작용성을 극대화합니다.
  * **자기 수정 능력:** 작업 실패 시 스스로 계획을 수정하고 재시도하는 능력을 부여합니다.

아키텍처 다이어그램 (Target):

```
graph TD
    A[사용자 목표 입력] --> B{Plan: 작업 그래프 생성};
    B --> C[Execute: 도구 실행];
    C --> D{Analyze: 결과 분석};
    D -- 추가 작업 필요 --> C;
    D -- 계획 수정 필요 --> F[Re-plan];
    F --> B;
    D -- 모든 작업 완료 --> E[최종 결과 생성];
```

### ✨ 주요 기능

#### v1.0

  * **React 기반의 반응형 UI:** 사용자 경험에 최적화된 동적 웹 인터페이스.
  * **API 기반 통신:** 프론트엔드와 백엔드 간의 안정적이고 확장 가능한 데이터 교환.
  * **모듈화된 백엔드:** 데이터 수집/정제 로직이 명확하게 분리되어 유지보수가 용이.

#### v2.0 (개발 중)

  * **그래프 기반 계획:** LangGraph를 활용한 정교한 작업 계획 수립.
  * **자율적 도구 사용:** 상황에 맞는 도구를 스스로 선택하고 실행.
  * **프론트엔드와 결합된 데이터 처리:** v1.0의 **데이터 수집/정제 로직을 프론트엔드와 통합**하여 더욱 빠르고 인터랙티브한 사용자 경험을 제공.

### 🎬 시작하기

사전 준비

  * **Node.js 및 npm/yarn:** v1.0 프론트엔드 실행에 필요.
  * **Python 3.9 이상:** v1.0 백엔드 및 v2.0 실행에 필요.
  * **OpenAI API 키:** v2.0 실행에 필요.

설치
리포지토리 복제 및 이동:

```bash
git clone https://github.com/yujinkim7123/Planner_AI_Agent.git
cd Planner_AI_Agent
```

가상 환경 생성 및 활성화 (Python):

```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate    # Windows
```

환경 변수 설정 (v2.0용):
프로젝트 루트에 `.env` 파일을 생성하고 API 키를 입력합니다.

```bash
OPENAI_API_KEY="sk-..."
```

### 🚀 v1.0 (Stable) 실행 방법

v1.0은 프론트엔드와 백엔드 서버를 각각 별도의 터미널에서 실행해야 합니다.

백엔드 에이전트 실행:

```bash
# 백엔드 의존성 설치
pip install -r requirements_backend_v1.txt  # (가정된 파일명)
# 백엔드 서버 실행
python backend/main.py  # (가정된 파일명)
```

(별도 터미널에서) 프론트엔드 실행:

```bash
# frontend 디렉토리로 이동
cd frontend
# 프론트엔드 의존성 설치
npm install
# 프론트엔드 개발 서버 실행
npm start
```

이제 웹 브라우저에서 `http://localhost:3000`으로 접속할 수 있습니다.
